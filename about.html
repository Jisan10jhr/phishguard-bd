About the project

Building a safer digital Bangladesh.

PhishGuard BD is an independent cybersecurity learning project designed to help people recognize suspicious URL patterns and become more aware of phishing risks.

Why PhishGuard BD?

Suspicious links can trick people into visiting deceptive websites or sharing sensitive information. This project highlights common URL warning signs and provides educational safety advice to encourage more careful browsing.

How it works

The current checker evaluates submitted URLs against a set of common warning patterns and presents a heuristic score with safety guidance. It does not perform live threat intelligence, redirect, or website-content checks.

Feedback and support

Found a bug or have an idea for improvement? Visit the project repository to review the code and share feedback through GitHub issues, if enabled.
